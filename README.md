# 📘 Theory of Computation — Practicals

A collection of **Theory of Computation (TOC) practicals** containing program implementations, code PDFs, execution screenshots, and simulation tool outputs for academic reference and practical exam preparation.

## 📂 Repository Contents

This repository includes:

- 💻 **Program Codes** — PDF files containing practical program implementations.
- 🖥️ **Execution Screenshots** — Screenshots demonstrating program execution and outputs.
- 🔄 **Simulation Tools** — Screenshots of automata and other TOC concepts simulated using relevant tools.
- 📄 **Practical Documentation** — PDF files organized for easy reference and revision.

## 🧠 Topics Covered

- Finite Automata
- Deterministic Finite Automata (DFA)
- Non-Deterministic Finite Automata (NFA)
- Regular Languages and Regular Expressions
- Context-Free Grammars (CFG)
- Other Theory of Computation practical exercises and simulations

*The topics listed may vary depending on the practicals included in the repository.*

## 🛠️ Languages & Tools

- **Programming Language:** C
- **Simulation Tools:** Automata simulation tools used in the practicals
- **Documentation:** PDF files with code, execution results, and screenshots

## 🎯 Purpose

This repository serves as a centralized collection of Theory of Computation practical work, making it easier to review implementations, understand execution results, refer to simulation outputs, and prepare for practical examinations.

## 📌 How to Use

1. Browse the repository to find the required practical.
2. Open the corresponding PDF file.
3. Review the program code and its execution screenshots.
4. Refer to the simulation screenshots to understand the corresponding concepts and results.
